# CineMatch

An AI-powered movie recommendation system placeholder. This is a lightweight landing page deployed to Vercel to establish a public HTTPS domain URL for TMDB application registration.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v3)
- **Deployment:** Vercel-compatible

## Local Development

First, make sure dependencies are installed:
```bash
npm install
```

Then, run the local development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment on Vercel

This repository is optimized for one-click Vercel integration:
1. Push the code to a GitHub repository.
2. Go to the Vercel Dashboard, import the repository, and click **Deploy**.
3. No environment variables or build parameters are required.
